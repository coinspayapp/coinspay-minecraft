# CoinsPay для Minecraft: установка

Плагин продаёт привилегии, наборы и услуги сервера за криптовалюту. Игрок вводит `/donate`,
выбирает товар и платит на странице CoinsPay. Плагин сам выполняет команды товара, а деньги
приходят сразу на ваши кошельки.

Где работает:
- **Spigot и Paper 1.8.8–1.21;**
- **Folia;**
- **сети на Velocity 3.3+ и BungeeCord.**

## 1. Ключ API

1. Зарегистрируйтесь на [coinspay.app](https://coinspay.app) и создайте магазин.
2. Добавьте в настройках магазина кошельки для выплат.
3. Откройте магазин → «Ключи API» → «Создать ключ», доступ — **«Только счета»**.

Такой ключ не умеет выплачивать деньги, поэтому утечка `config.yml` ничем не грозит.

Для пробы отметьте «Тестовый ключ» (`cpk_test_…`). На странице оплаты тестового счёта есть
кнопка «Оплатить», и настоящие деньги не списываются.

## 2. Установка

1. Положите `CoinsPay-<версия>.jar` в папку `plugins/` и перезапустите сервер.
2. Откройте `plugins/CoinsPay/config.yml` и впишите ключ в `api.key`.
3. Опишите товары в `packages` (ниже).
4. Выполните `/coinspay reload`, затем `/coinspay status`. Должен быть виден ваш магазин и
   ключ «test» или «live» с доступом `invoices`.

## 3. Товары

```yaml
packages:
  vip-30:                       # id товара: латиница, цифры, _ и -
    name: "&6VIP на 30 дней"    # название в меню и в счёте, цвета через &
    description:
      - "Золотой ник и /hat"
    icon: GOLD_INGOT            # предмет в меню
    price: "4.99"               # цена в валюте currency (по умолчанию USD)
    commands:                   # команды от консоли после оплаты, без /
      - "lp user {player} parent addtemp vip 30d accumulate"
```

В командах можно подставлять:
- `{player}` — ник;
- `{uuid}`;
- `{package}` — id товара;
- `{amount}`, `{currency}` — цена и валюта;
- `{invoice}` — номер счёта.

### Привилегии и права (VIP, модератор, админ)

Права выдаёт ваш плагин прав, CoinsPay только выполняет его команду. Такие команды работают
и для игрока не в сети, поэтому выдача не ждёт его входа.

- **LuckPerms.** Срок LuckPerms ведёт сам:
  `lp user {player} parent addtemp vip 30d accumulate`. С `accumulate` повторная покупка
  продлевает срок.
- **Без LuckPerms.** Срок может вести CoinsPay:

  ```yaml
    admin-7:
      name: "&cАдмин на 7 дней"
      price: "10"
      duration: 7d               # 30d, 12h, 90m, 2w, 1mo
      commands: ["op {player}"]
      expire-commands: ["deop {player}"]
  ```

  Когда срок выйдет, `expire-commands` выполнятся, даже если игрок не в сети. Повторная покупка
  продлевает срок.

### Предметы и наборы

Для `give` и наборов поставьте `require-online: true`. Если игрок оплатил и вышел, товар
выдадут, когда он зайдёт.

## 4. Как покупает игрок

1. `/donate` открывает меню. Если указать `menu: chat`, вместо меню в чате будет список
   с кнопками.
2. Клик по товару создаёт счёт. В чате появится ссылка на оплату, а в руке — карта с QR-кодом
   ссылки: её удобно отсканировать телефоном.
3. Игрок платит на странице CoinsPay в USDT, BTC, ETH, TRX, BNB, LTC, SOL и других монетах.
4. Через несколько секунд после оплаты плагин пишет «Оплата получена» и выполняет команды.

Плагин сам спрашивает CoinsPay об оплате раз в `poll-seconds`, поэтому серверу не нужен ни
внешний адрес, ни вебхук.

## 5. Сеть серверов

- **Плагин на прокси** (Velocity или BungeeCord): `/donate` работает на всех серверах, а
  команды выполняются в консоли прокси. Это подходит, например, для LuckPerms на прокси:
  `lpv` на Velocity, `lpb` на BungeeCord.
- **Плагин на серверах сети:** ставите его на нужные сервера. Каждому серверу — свой
  `server-id`, ключ может быть общим. Товар выдаётся на том сервере, где его купили.

## 6. Команды

| Команда | Что делает |
|---|---|
| `/donate [товар]` | магазин |
| `/coinspay status` | ключ, магазин, очередь, последняя ошибка API |
| `/coinspay pending` | неоплаченные и ожидающие счета, действующие сроки |
| `/coinspay check <счёт>` | проверить счёт сейчас |
| `/coinspay redeliver <счёт>` | выполнить команды товара ещё раз |
| `/coinspay markdone <счёт>` | отметить выданным без команд |
| `/coinspay give <игрок> <товар>` | выставить счёт игроку в сети |
| `/coinspay reload` | перечитать `config.yml` и тексты |

Права: `coinspay.donate` — у всех; `coinspay.admin` — у операторов.

## Важно

- **Выдача ровно один раз.** Если сервер упал посреди выдачи, плагин не выдаёт товар повторно.
  Он пишет в консоль номер счёта. Проверьте, получил ли игрок товар, и выполните
  `/coinspay redeliver <счёт>` или `/coinspay markdone <счёт>`.
- **Сервера без лицензии.** На них ник не защищён, и права по нику получит любой, кто зайдёт
  под этим именем. Нужна авторизация, например AuthMe.
- **Правила Mojang.** Платное игровое преимущество (pay-to-win) правила Mojang запрещают.
  За то, что продаёт сервер, отвечает его владелец.
- **Тексты.** Тексты для игроков лежат в `messages_ru.yml` и `messages_en.yml`. Язык
  выбирается по клиенту игрока, `language: ru` или `en` закрепляет один язык.
